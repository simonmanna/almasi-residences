# Real-Estate-Website — Almasi Residence

## Project
Almasi Residence sales site: Kigali luxury residences. NestJS+Prisma API (:3001), Next.js web (:5173), Docker Postgres/Redis/MinIO. Turborepo monorepo (pnpm).

## Load These Skills for Design Work

When designing or auditing UI for this project, load:

- **web-design-guidelines** — Review UI code for Vercel Web Interface Guidelines compliance (accessibility, forms, animation, typography, touch)
- **image-to-code** — Generate design images first, analyze, then implement the website to match
- **awesome-design** — Use DESIGN.md files from 70+ top-tier sites (Stripe, Linear, Apple, Nike) for consistent, premium UI
- **ui-ux-pro-max** — Design system generation (79 styles, 192 palettes, 192 reasoning rules). CLI: `uipro init --ai universal`
- **taste-skill** — Anti-slop frontend design — infers design direction and ships non-templated interfaces. Install: `npx skills add Leonxlnx/taste-skill`
- **design-md** — Author/validate Google's DESIGN.md token spec files
- **popular-web-designs** — 54 real design systems as HTML/CSS reference
